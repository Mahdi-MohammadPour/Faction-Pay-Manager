# مدیریت حقوق پلیرها

سلام 👋

این یه ابزار کوچیک و سبکه برای مدیریت حقوق پلیرها توی فکشن‌ها (مثلاً پلیس، امداد، مافیا یا هر چیزی که خودت داری) — اینکه هر پلیر توی کدوم فکشنه، چه فعالیتی انجام داده، هر فعالیت چقدر می‌ارزه و در نهایت هر کس چقدر باید حقوق بگیره.

کل پروژه فقط با HTML و CSS و جاوااسکریپت خام نوشته شده؛ نه فریمورکی داره نه بک‌اندی، و دقیقاً به همین خاطر می‌تونی بدون دردسر روی GitHub Pages سوارش کنی. نه هاست می‌خوای نه دامنه، فقط یه Repository.

## چه کارهایی ازش برمیاد

- فکشن بسازی
- پلیر اضافه کنی و به یه فکشن وصلش کنی
- آیتم یا فعالیت تعریف کنی و قیمت هر واحدش رو بذاری (مثلاً «دستگیری» بشه ۵۰۰)
- هر بار یه پلیر یه فعالیت انجام داد، تعدادش رو ثبت کنی تا خودش حساب کنه
- گزارش کامل هر پلیر رو ببینی، جستجو کنی یا بر اساس فکشن فیلتر کنی
- هر چی لازم نبود حذفش کنی — پلیر، فکشن، آیتم، یا فقط یه رکورد خاص

## تازگی خروجی/ورودی هم اضافه شده

تا قبل از این، اطلاعات فقط توی `localStorage` همون مرورگر ذخیره می‌شد؛ یعنی اگه سایت رو یه جای دیگه باز می‌کردی یا می‌خواستی اطلاعاتت رو بدی به یه نفر دیگه، راهی نبود. الان دیگه هست:

- دکمه‌ی **«خروجی گرفتن»** یه فایل JSON از همه‌چیز (فکشن‌ها، پلیرها، آیتم‌ها، رکوردها) می‌سازه و برات دانلودش می‌کنه.
- دکمه‌ی **«وارد کردن فایل»** همون فایل رو از هر جایی می‌گیره — گوشی، کامپیوتر دیگه، هر مرورگری — و جایگزین اطلاعات فعلی می‌کنه.

پس می‌تونی از سیستمت خروجی بگیری، فایل رو بفرستی برای یه نفر دیگه یا خودت روی یه دستگاه دیگه بازش کنی، اون طرف هم فایل رو وارد می‌کنه و دقیقاً همون‌جایی که تو ول کردی ادامه می‌ده. چون این کار اطلاعات فعلی رو جایگزین می‌کنه، قبلش یه تأییدیه هم ازت می‌پرسه که دستی‌دستی چیزی پاک نشه.

## ساختار فایل‌ها

```text
player-pay-calculator/
├── index.html
├── style.css
├── app.js
└── README.md
```

## یه نکته درباره ذخیره‌سازی

هنوز هم پایه‌ی کار همون `localStorage` مرورگره، یعنی به‌طور پیش‌فرض اطلاعات همون‌جا می‌مونن. فایل خروجی/ورودی دقیقاً همین محدودیت رو جبران می‌کنه و اجازه می‌ده اطلاعات رو جابه‌جا کنی. اما اگه دنبال یه نسخه‌ی واقعی چندکاربره‌ای، با یه دیتابیس مشترک و سیستم ورود، اون یه قدم جلوتره و به یه بک‌اند نیاز داره.

## گذاشتنش روی GitHub Pages

راستش کارش خیلی ساده‌ست:

1. یه Repository عمومی (Public) توی گیت‌هاب بساز، مثلاً با اسم `player-pay-calculator`.
2. فایل‌های `index.html`، `style.css`، `app.js` و `README.md` رو مستقیم توی ریشه‌ی همون Repository بذار، نه داخل یه پوشه‌ی اضافه.
3. برو توی `Settings → Pages`، توی بخش `Build and deployment` گزینه‌ی `Deploy from a branch` رو بزن، بعد `Branch: main` و `Folder: /(root)` رو انتخاب کن و `Save` کن.
4. چند لحظه صبر کن. آدرس سایتت یه همچین شکلی می‌شه:

```text
https://username-خودت.github.io/player-pay-calculator/
```

نه هاست لازم داری نه دامنه؛ گیت‌هاب خودش همه‌ی این کارها رو انجام می‌ده.

هر بار هم که یکی از فایل‌ها رو توی Branch اصلی عوض کنی و Commit بزنی، نسخه‌ی آنلاین خودکار به‌روز می‌شه. لازم نیست سرور محلی هم بالا بیاری (مثل `python -m http.server`)؛ گیت‌هاب پیجز مستقیم `index.html` رو منتشر می‌کنه.
